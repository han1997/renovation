# PRD：装修管家 · 新房装修全流程助手

## 背景与需求（来自用户 2026-08-03）

用户即将装修新房，完全没有装修经验。需要一个软件：

1. 先通过网络调研普通人装修商品房的流程、注意事项、价格等信息；
2. 为小白梳理装修全过程；
3. 全程辅助：预算管理、步骤分析、注意事项提醒、风格选择等（开放式需求，自行扩展）。

形式未定（web / 小程序 / app 均可接受），由实现者决策。

## 决策记录

- **形式**：本地纯静态 Web 应用（HTML/CSS/vanilla JS，零依赖、零构建），双击 index.html 即用；
  附 `server.js` + `phone-server.bat` 支持手机局域网访问。理由：零门槛、可迭代，
  知识库与逻辑将来可平移到小程序/App。
- **数据**：localStorage 持久化 + JSON 导入导出备份 + 支出 CSV 导出；无后端、无账号。
- **知识来源**：4 个调研代理并行检索中文互联网（2024–2026 内容），覆盖流程/价格/避坑验收/风格软装，
  结论沉淀于 `js/data/knowledge.js` 与 `js/data/prices.js`，来源清单见 `research/sources.md`。

## 功能范围（MVP）

- 首次设置向导（面积/城市档/装修方式/档次 → 生成预算模板与总价估算）
- 首页仪表盘：当前阶段、总进度、预算使用、待办提醒（按任务日期，逾期高亮）、本阶段避坑
- 流程页：14 阶段时间轴，任务打卡、自定义任务、计划日期、阶段避坑、购买清单、验收入口
- 预算页：分类预算（可增删改）、支出记账（CRUD）、超支预警、行情参考价库、CSV 导出
- 指南页：避坑指南（可搜索/分主题）、验收清单（可勾选）、风格库+风格测试、建材购买日历、装修方式百科+黑话词典
- 我的页：房屋信息编辑、笔记、通讯录、数据备份/恢复/清空

## 非目标

- 云同步 / 多设备实时同步（用导入导出替代）
- 推送通知（本地应用无后台，提醒以打开应用时的仪表盘形式呈现）
- 小程序/App 打包（后续可选）
